# Chapter 28: Secure Inputs and Measurable Risk Reduction

> **Scaffold status:** Planned chapter; lesson and full lab are intentionally deferred.

## Learning objectives

- Apply allow-list validation.
- Test malicious inputs.
- Report security findings without overstating safety.

## Measurable-outcome concept

Security control effectiveness.

## Planned Harbor FCU scenario

In the entirely fictional Harbor FCU simulation, learners will harden a fictional transfer memo endpoint.

## Metrics to measure

- Invalid inputs rejected.
- False rejection rate.
- Open findings.

## Planned executable exercise

Run a table of benign and hostile inputs before and after validation.

## Expected takeaway

A fixed finding reduces a demonstrated exposure, not all security risk.
