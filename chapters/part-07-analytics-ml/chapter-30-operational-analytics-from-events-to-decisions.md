# Chapter 30: Operational Analytics: From Events to Decisions

> **Scaffold status:** Planned chapter; lesson and full lab are intentionally deferred.

## Learning objectives

- Create trustworthy aggregates.
- Validate data quality.
- Map analysis to decisions.

## Measurable-outcome concept

Decision-oriented operational analytics.

## Planned Harbor FCU scenario

In the entirely fictional Harbor FCU simulation, learners will summarize authentication demand and failure patterns.

## Metrics to measure

- Event completeness.
- Failure rate by segment.
- Query freshness.

## Planned executable exercise

Build and validate a daily operational dataset.

## Expected takeaway

Analytics creates value when a defined decision uses reliable data.
