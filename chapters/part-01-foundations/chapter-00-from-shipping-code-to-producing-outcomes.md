# Chapter 0: From Shipping Code to Producing Outcomes

> **Scaffold status:** Planned chapter; lesson and full lab are intentionally deferred.

## Learning objectives

- Classify outputs, metrics, outcomes, and impacts.
- Trace a defensible outcome chain.

## Measurable-outcome concept

Outcome-chain vocabulary and bounded claims.

## Planned Harbor FCU scenario

In the entirely fictional Harbor FCU simulation, learners will review a balance API change and separate what shipped from what was observed.

## Metrics to measure

- Request count.
- Success rate.
- P95 latency.

## Planned executable exercise

Run the baseline measurement command and label each reported value in the outcome chain.

## Expected takeaway

A shipped feature is evidence of activity, not evidence of improvement.
