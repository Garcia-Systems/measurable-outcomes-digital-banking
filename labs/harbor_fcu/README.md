# Harbor FCU evolving lab

This directory is the home of the single evolving simulation used throughout the book. Harbor FCU and every lab artifact are fictional. The initial baseline uses `../../data/synthetic/api_requests.csv`; future chapters will add versioned scenarios here while sharing models and measurement utilities from `src/harbor_fcu`.

Do not create unrelated per-chapter applications. Each exercise should document its baseline, change, repeated measurement, comparison, and appropriately bounded outcome claim.
