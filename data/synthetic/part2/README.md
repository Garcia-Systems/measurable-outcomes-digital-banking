# Part II synthetic member journeys

`application_before.csv` and `application_after.csv` contain deterministic events for 60 fictional sessions (`session_0001` onward). They were generated by `python3 scripts/generate_member_journey.py`; regeneration produces byte-identical files. `duration_ms` is elapsed time since the preceding event, timestamps are UTC, and `result=error` is a synthetic experience signal. No row comes from a person, account, production tracker, or analytics export.
